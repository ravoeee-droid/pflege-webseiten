# Pflege-Webseiten.de

Branchenmarke von Digitale Gewinner für hochwertige Webseiten und digitales Wachstum speziell für Pflegeunternehmen.

## Positionierung

Die Website ist das Fundament. Wir machen Pflegeunternehmen online attraktiver, damit Angehörige schneller Vertrauen fassen, mehr Pflegekräfte aufmerksam werden und mehr passende Menschen den Weg zum Unternehmen finden.

## Sprache

- kurze, einfache Sätze
- kein Marketing-Fachchinesisch
- Nutzen vor Technik
- Pflegealltag und echte Entscheidungssituationen
- Vertrauen, Arbeitgeberattraktivität, Sichtbarkeit und einfache Kontaktwege

## Story-Struktur

1. Glasklarer Hero
2. Angehörige und Bewerber als echte Alltagssituationen
3. Website als Fundament
4. Besser aussehen
5. Besser gefunden werden
6. Mehr Menschen erreichen
7. Einfacher Kontakt
8. Pflege-Webseiten-Methode
9. Spezialisierung auf Pflege
10. Kostenloser Konzeptentwurf als No-Brainer-Einstieg
11. FAQ
12. Emotionaler Abschluss

## Entwicklung

```bash
npm install
npm run dev
```

Produktionsprüfung:

```bash
npm run build
npm run lint
```

## Aktueller Arbeitsstand

Der Foundation-Build liegt auf `build/pflege-webseiten-foundation`. Keine Veröffentlichung oder Zusammenführung in `main`, bis der Stand visuell geprüft und ausdrücklich freigegeben wurde.
